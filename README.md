# Blog d’Aurélien Giroux

Dépôt source de mon blog personnel, construit avec [Hugo](https://gohugo.io/) et le thème [Stack](https://github.com/CaiJimmy/hugo-theme-stack), puis publié avec GitHub Pages.

Le site rassemble des articles, notes de recherche et essais, notamment autour de la finance quantitative, des probabilités, de l’épistémologie et de la modélisation.

## Publication

Les sources du site sont déployées automatiquement par GitHub Actions après chaque modification de la branche principale.
